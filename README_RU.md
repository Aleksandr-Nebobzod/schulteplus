# Schulte Plus — Обзор проекта

**Версия:** 116 "Entada" · **Платформа:** Android (minSdk 26, targetSdk 35) · **Язык:** Java
**Пакет:** `org.nebobrod.schulteplus` · **Лицензия:** Apache 2.0 · **Автор:** Smart Rovers

---

## Что это?

Мобильное приложение для когнитивных тренировок. Три направления упражнений — таблицы Шульте, визуальные иллюзии (Basics) и SSSR — с настраиваемой сложностью, системой достижений и внутриигровой валютой (псикойны). Данные синхронизируются между локальной SQLite-базой и облаком Firebase.

## Пространства упражнений

| Пространство | Префикс ID | Суть |
|---|---|---|
| **Schulte** | `gcb_sch*` | Таблицы Шульте: 1–4 последовательности, числа/буквы/цвета, настраиваемое поле 5×5…10×10 |
| **Basics** | `gcb_bas*` | Визуальные упражнения: куб Неккера, треугольник Пенроуза, точки, цветовые круги, танцующие силуэты |
| **SSSR** | `gcb_sss*` | Тренировка распределения времени по сферам жизни (работа, отдых, семья и т.д.) |
| **Schulte Parents** | `gcb_space_schulte_parents` | Упражнения для родителей с детьми |

## Как устроен код

```
84 исходных файла Java, ~40 XML-разметок, 80+ ресурсных drawable
```

### Три слоя архитектуры:

**1. Движок упражнений (`common/`)** — 11 файлов
- `ExerciseRunner` — синглтон-диспетчер: хранит состояние пользователя, настройки, запускает и завершает упражнения, считает статистику
- `STable` — таблица Шульте: сетка ячеек `SCell`, вероятностное распределение, перемешивание, журнал ходов, расчёт результатов (среднее, СКО)
- `Const` — интерфейс со всеми ключами настроек, ID упражнений, флагами достижений

**2. Данные (`data/`)** — 20 файлов
- Паттерн двойного репозитория: `DataRepos` → `DataOrmRepo` (SQLite/ORMLite) + `DataFirestoreRepo` (Firestore). Запись в оба, при чтении — разрешение конфликтов по timestamp
- 6 таблиц: `exresult`, `achievement`, `turn`, `userhelper`, `adminnote`
- `ExType` — метаданные упражнений из `res/raw/ex_types.json` (условия разблокировки, стоимость, сертификация)

**3. UI (`ui/`)** — 30+ файлов
- `MainActivity` — центр приложения: нижняя навигация (Dashboard / Новости / Настройки / Ещё), FAB запуска упражнений, onboarding-подсказки
- Три activity упражнений: `SchulteActivity`, `BasicsActivity`, `SssrActivity` — полноэкранные, с сеткой, тулбаром и диалогом результатов
- Dashboard на ViewPager: состояние → достижения → история результатов
- Навигация через Android Navigation Component (`mobile_navigation.xml`)

### Поток аутентификации:
`SplashActivity` → авто-вход или `LoginActivity`/`SignupActivity` → `MainActivity`

## Система прогресса

- **Псикойны** — игровая валюта: начисляются за упражнения (время × сложность), тратятся на открытие новых упражнений
- **Уровень** — растёт с накоплением часов практики: `level = √(totalHours)`
- **Достижения** — значки за рекорды, часы, уровни, непрерывные дни тренировок
- Упражнения могут требовать: прохождение квиза (`certRequired`), покупку за псикойны (`price`), выполнение условий

## Ключевые особенности

- **Вероятностное распределение** ячеек таблицы Шульте — функция `camelSurface()` смещает внимание пользователя в заданную область поля
- **Типы символов**: числа, римские цифры, латиница, кириллица, деванагари, цветовые градиенты
- **Демо-режим** — встроенный пользователь `AvtKMUW82...` для тестирования без регистрации
- **Русская локализация** — полный перевод интерфейса (`values-ru/`)
- **Тёмная тема** — `values-night/` с альтернативной палитрой
