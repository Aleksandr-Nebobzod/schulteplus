Рейтинги

-- это главный параметр, открывающий доступ к прочим параметрам (опциям)

При включенных Рейтингах результаты сопоставимы с другими участниками.

При выключенных Рейтингах результаты считаются тренировочными. Для удобства индивидуальных тренировок можно настроить:
Cтатус, Перемешивание, Ширина, Высота, Квадраты, Тип символа, Вероятности.
