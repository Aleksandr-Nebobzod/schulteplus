## Подробности
### D-29 динмические цвета SWG
####  💻 Программное изменение конкретных путей 
Это самый гибкий путь, позволяющий выбирать конкретные слои. В XML каждый `path` получает уникальное имя.
```xml
<vector ...>
    <path
        android:name="cloud"
        android:pathData="..."
        android:fillColor="#9f9" />
    <path
        android:name="sun"
        android:pathData="..."
        android:fillColor="#fff" />
</vector>
```
Затем динамически меняем цвет только элемента `cloud` :

```kotlin
// 1. Получаем drawable
val drawable = AppCompatResources.getDrawable(this, R.drawable.my_vector) as VectorDrawableCompat

// 2. Ищем нужный путь
val cloudPath = drawable.getPath("cloud") 

// 3. Меняем цвет
cloudPath.fillColor = ColorStateList.valueOf(Color.parseColor("#ffffff"))

// 4. Обновляем отображение
drawable.invalidateSelf() 
imageView.setImageDrawable(drawable)
```
Для получения доступа к вложенному `path` в `AnimatedVectorDrawable` можно также использовать рекурсивный обход `drawable`, но в `VectorDrawableCompat` (в большинстве версий) метод `getPath(name)` является стандартным решением.
