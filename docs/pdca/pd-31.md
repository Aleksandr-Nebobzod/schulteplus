# PD-31 — Три режима кегля символов (prf_font_scale)

Статус: 🔄 в работе (тест-репорт — А.М.)

**Названия режимов: normal / max / stretch** (RU: норма / макс / искажён) — суммарий скроллера `lbl_font_scale_sum`.

## Постановка задачи (кратко)

Переобозначить скроллер размера шрифта (`SeekBarPreference prf_font_scale`, значения −1..1)
на три режима кегля, применимых в классике Шульте (S1–S3) и «Мешанине» (S4):

- **−1 — маленький**: символ ½ длины и ½ ширины ячейки (классика); «Мешанина» — символ 1:1 с ячейкой, единый кегль для всех плиток.
- **0 — максимальный**: классика — единый кегль по самому длинному символу последовательности `min(высота ячейки, ширина ячейки / ширина самого длинного)`; «Мешанина» — каждое число вписывается в свою плитку без искажения (`min(tileW/textW, tileH/textH)`).
- **1 — плитка**: stretch без измерений (искажение пропорций): классика — ячейка, «Мешанина» — плитка («1» — искажённо широкая, двоичные коды — «забор»).

## Подробности

| Значение | Классика (S1–S3) | «Мешанина» |
|---|---|---|
| **−1 маленький** | символ ½ длины и ½ ширины ячейки | символ 1:1 с ячейкой — единый кегль для всех плиток (в плитке 2×2 — ¼ её площади) |
| **0 максимальный** | единый кегль по самому длинному символу последовательности: `min(высота ячейки, ширина ячейки / ширина самого длинного)` | каждое число вписано в свою плитку без искажения (`min(tileW/textW, tileH/textH)`) |
| **1 плитка** | stretch на ячейку без измерений — новый `StretchTextDrawable` («1» — искажённо широкая, «1111» — забор) | stretch по площади плитки (как раньше, TP-15) |

**Ключевые компоненты:**

- `GridAdapter.longestSymbol()` — специальный метод измерения самого длинного символа **в текущем упражнении** (проходит `area` — реальные тексты ячеек: для 2×2 римские до «IV», для 10×10 — «XXV»; не зависит от типа символа);
- `GridAdapter.calcTextSize()` — кегль классики по режиму;
- `PavedCellDrawable.setNumber(..., mode)` — три масштаба (равномерный по ячейке / вписать в плитку / stretch);
- `StretchTextDrawable` — новый drawable для классики в режиме «плитка» (поверх `ic_border` через `LayerDrawable`, рамка не меняется);
- Суммарий скроллера: `lbl_font_scale_sum` (RU/EN) в `preferences_schulte.xml`.

**Единый контейнер, разные правила**: классика и «Мешанина» используют один и тот же скроллер, но семантика режима 0 разная (единый кегль по самому длинному vs пер-плитка вписывание) — потому что в классике ячейки одинаковые (единый кегль логичен), а плитки разные (вписывать каждое число в свою). Один преф, два осознанных поведения.

**`longestSymbol()` через area, а не шаблон** — точнее и без правок чужого кода: area уже содержит финальные тексты (после `shuffle()` они не меняются — только переставляются), плюс покрывает будущие типы символов автоматически.

**Проверки:** javac ✅, XML ✅. Тест на устройстве: три положения скроллера в классике и «Мешанине».
