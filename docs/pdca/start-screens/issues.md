## Правила

- Новые сверху таблицы. 
- Одна строка = один дефект; минимальный путь воспроизведения (Given/When/Then).
- Скриншоты/логи — в `temp/`, в таблице указывать имена файлов.
- Критичность: 0 блокер (релиз стоп) / 1 мажор (функция не работает) / 4 минор (работает, но плохо) / 5 косметика.
- Статусы: `открыт` → `в работе` → `готов к проверке` → `подтверждено` | `не баг` | `дефер` (причина — в колонке «Ожидание»).
- Отклонение от макета/ТЗ — дефект; предложение изменить макет/ТЗ — «новое требование» → Decisions.md.
