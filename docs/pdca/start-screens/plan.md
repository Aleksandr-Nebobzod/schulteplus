> **Руководитель проекта:** Claude Code (координация субагентов). **Статус:** инициализация.
> Спецификация: `docs/TZ_StartScreens_Redesign.md` (§6 — открытые вопросы = входной шлюз).
> Бэклог: `SP-03 [S]`. Решения фиксируются в `docs/Decisions.md`.

## Гипотеза

Стартовый флоу B2 функционален, но минимален (нет reset/delete/resend, инлайн-валидации,
брендинга, welcome-онбординга). Редизайн сделает старт быстрым и понятным, вернёт
отложенные функции (B2.1) и познакомит новых пользователей с приложением.

**Измеримые ожидания:**
- Время от холодного старта до первого действия: ~2.1 c → ≤ ~1 c
- Восстановлены: сброс пароля, resend verification, delete-account (re-entry)
- Онбординг для новых пользователей (первый запуск после входа), связан с `shownIntros`
- Инлайн-валидация форм вместо тостов; единый визуальный стиль (брендинг, тёмная тема)

## Координация

- **Субагенты**: дизайн → **`mobile-design`** (зарегистрирован 16.08, `.claude/agents/mobile-design.md`):
  Material3-токены (светлая/тёмная), компоненты форм, структура онбординга в коде +
  PNG-превью (Roborazzi/Paparazzi) на утверждение пользователю, сверка скриншотов
  устройства с ТЗ; реализация → инкременты с assembleDebug; QA → `quality-engineer`
  (проверка сценариев S1–S6).
- **Границы**: не пересекаться с параллельным агентом SP-04 («Мешанина»); не трогать
  релизный путь (v119/120) до smoke B2.
- **Правила**: каждая итерация зелёная сборка + коммит; решения — в Decisions.md.
